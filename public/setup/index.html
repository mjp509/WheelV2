Welcome!

WheelV2 is a Twitch channel point wheel overlay for OBS. When a viewer redeems a channel point reward, the wheel spins — win and get VIP, lose and get timed out!

This wizard will walk you through connecting your Twitch account, picking a channel point reward, and getting the overlay into OBS.

Create a Twitch Application

  1. Go to dev.twitch.tv/console/apps and log in.
  2. Click "Register Your Application".
  3. Set the Name to anything (e.g. "WheelV2").
  4. Add this OAuth Redirect URL:
    http://localhost:3000/setup/callback.html
  5. Set Category to "Chat Bot".
  6. Click Create, then click Manage on your new app.
  7. Copy the Client ID and paste it below.

Connect with Twitch

Click the button below to authorize WheelV2 with your Twitch account. A popup will open for you to log in and approve permissions.

Select Channel Point Reward

Choose the channel point reward that will trigger the wheel spin. If you haven't created one yet, go to your Twitch dashboard and create a custom reward first.

You're all set!

The bot is now running. Add the overlay to OBS:

  1. In OBS, add a Browser Source.
  2. Set the URL to:
    http://localhost:3000
  3. Set Width to 800 and Height to 800.
  4. Set FPS to 60.
  5. Click OK — you're live!
